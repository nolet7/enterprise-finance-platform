# Operating and security notes

Cloud SQL generates recurring expenses even with zero Cloud Run instances. Set a billing budget first; alerts do not enforce a spending limit. Use a separate lab project. Configure WIF identity for GitHub Actions instead of long-lived account keys. Require Cloud Run invoker IAM. Use a dedicated minimal runtime service account. Store the database URL in Secret Manager and restrict Terraform state because it can contain secrets. Build tagged immutable images and deploy by digest. Do not handle real customer records. Replace schema create_all with reviewed Alembic migrations and one-off migration jobs. Before production add private Cloud SQL networking, high availability, restore drills, structured tracing, SLO alerts, load tests, key rotation, threat modeling and deployment approvals. No infrastructure is auto-deployed.
